# SprintGames

Четыре мини-игры (Танки, Сумо, Следы, Кристаллы) для 1–4 игроков на одном компьютере или по сети.
Можно играть с компьютера (клавиатура) и с телефона (джойстик и кнопка на экране).

## Сервер на этом компьютере

Сервер запускается **сам при входе в Windows** (ярлык «Арена - сервер» в папке «Автозагрузка»).

- Запустить вручную: `start-server.ps1` (правой кнопкой → «Выполнить с помощью PowerShell») или `node server.js`.
- Остановить: `stop-server.bat`.
- Журнал работы: `server.log`, ошибки: `server-errors.log`.
- Отключить автозапуск: Win+R → `shell:startup` → удалить ярлык «Арена - сервер».

## Как подключиться с другого устройства

Все устройства должны быть в одной сети:

- **Общий Wi-Fi** — все подключены к одному роутеру.
- **Точка доступа этого компьютера** — Параметры → Сеть и Интернет → Мобильный хот-спот → Вкл.
  Телефоны подключаются к этой Wi-Fi сети, адрес игры обычно `http://192.168.137.1:3000`.
- **Точка доступа телефона** — компьютер и остальные подключаются к Wi-Fi телефона.

Дальше на любом устройстве открыть в браузере адрес игры. Его и QR-код показывает сама игра:
«Играть онлайн» → внизу блок «Подключить телефон или другой компьютер».

При первом запуске Windows спросит про брандмауэр для Node.js — нужно разрешить доступ
(для точки доступа компьютера может понадобиться отметить и «общественные сети»).

## Приложение SprintGames на телефон

В меню есть кнопка **«Скачать приложение»**:
- на компьютере она показывает QR-код — откройте игру на телефоне;
- на **Android** — скачивается настоящее приложение `SprintGames.apk` (во весь экран, своя иконка,
  игра с ботом работает без сети, онлайн сам находит сервер в Wi-Fi). При установке Android попросит
  разрешить установку из браузера — это нормально для приложений не из Google Play;
- на **iPhone** (Safari) → «Поделиться» → «На экран Домой».

### Сборка APK

```
node android/build-apk.js
```

Нужны JDK и Android SDK (`build-tools/34.0.0`, `platforms/android-34`, по умолчанию в `C:\Users\User\android-sdk`).
Готовый файл — `SprintGames.apk` в папке игры, сервер отдаёт его по адресу `/SprintGames.apk`.

**Ключ подписи** — `android/sprintgames.jks` и пароль в `android/keystore.properties`. Их нет в git.
Сохраните их копию: без этого ключа новые версии не установятся поверх старой (придётся удалять приложение).

Иконки сайта перерисовать: `node gen-icons.js`.

## Телефон

- Играть лучше горизонтально.
- Левая половина экрана — джойстик: коснитесь где угодно и ведите палец туда, куда нужно ехать.
- Правая половина экрана — действие (огонь / рывок / прыжок). Пауза — кнопка вверху по центру.
- На одном телефоне — режим «1 + бот»; с друзьями — через «Играть онлайн».

## Как устроен онлайн

- Сервер хранит список комнат («серверов») и пересылает данные между игроками.
- Кто создал сервер — хост: игра считается у него, остальные отправляют ему нажатия.
