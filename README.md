# Арена на четверых

Четыре мини-игры (Танки, Сумо, Следы, Кристаллы) для 1–4 игроков на одном компьютере или онлайн.

## Запуск сервера у себя

```
npm install
node server.js
```

Игра откроется по адресу http://localhost:3000.
Друзья в той же сети (Wi‑Fi) заходят по адресу, который сервер выводит при запуске, например `http://192.168.1.5:3000`.
При первом запуске Windows спросит про брандмауэр — разрешите доступ для частных сетей.

## Чтобы играли друзья через интернет

Нужно разместить сервер в интернете. Самый простой бесплатный вариант — Render.com:

1. Загрузите папку на GitHub (файлы `index.html`, `server.js`, `package.json`; папку `node_modules` загружать не нужно).
2. На render.com: New → Web Service → выберите репозиторий.
3. Build command: `npm install`, Start command: `node server.js`.
4. Через пару минут появится адрес вида `https://arena-xxxx.onrender.com` — его и отправляйте друзьям.

Быстрый вариант без размещения: пока сервер запущен у вас, выполните `npx localtunnel --port 3000`
(или `cloudflared tunnel --url http://localhost:3000`) и отправьте друзьям выданную ссылку.

## Как устроен онлайн

- Сервер хранит список комнат («серверов») и пересылает данные между игроками.
- Кто создал сервер — хост: игра считается у него, остальные отправляют ему нажатия клавиш.
- В поле «Адрес сервера» можно вписать чужой сервер, если кто-то запустил свой.
